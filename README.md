# Канбан — настольная доска со стикерами

![Доска с несколькими проектами](artifacts/preview.png)

Личный канбан на компьютере: рабочий лист, разлинованный на колонки, а задачи — стикеры, которые можно двигать свободно. Всё хранится локально: без облака, аккаунтов и подписок.

## Что это

Канбан помогает держать поток задач на виду: колонки показывают этапы, стикеры движутся слева направо, а количество незавершённой работы можно ограничить. Приложение переносит этот принцип на обычный рабочий стол — без командных досок, уведомлений и интеграций.

## Возможности

### Доска

- **Пять колонок по умолчанию** — «Пул задач», «Срочные», «В работе», «На ожидании», «Завершено». Колонки добавляются кнопкой «＋ Колонка», переименовываются кликом по заголовку и удаляются.
- **Свободная раскладка.** Стикер остаётся там, где его положили, и может стоять на границе колонок. При перетаскивании двигается сам стикер — без призрака и задержек.
- **Магнит и расталкивание.** Стикер прилипает к центру дорожки, краям соседей и сетке. Если он наехал на другой стикер, тот мягко сдвигается вниз. Выросший при дописывании стикер тоже подталкивает нижние, чтобы они не оказались под ним.
- **Упорядочить.** Кнопка в верхней панели раскладывает все стикеры ровными стопками по центру своих колонок.
- **Прокрутка средней кнопкой.** Зажми колесо мыши и веди доску в любую сторону — как в графических редакторах.

### Задачи

- **Создание в один клик.** Клик по пустому месту — и сразу можно печатать, как в OneNote. Клик мимо сохраняет черновик.
- **Правка на месте.** Клик по стикеру — правка текста без модального окна. Карандаш ✎ открывает полную карточку с меткой, цветом и сроком. В тексте есть жирный, курсив, списки и размер шрифта; отмена и повтор работают внутри правки.
- **Мультивыделение.** Рамка-протяжка и Shift+клик выделяют несколько стикеров. Их можно перенести всей пачкой или удалить с возможностью вернуть.
- **Метки, цвета и сроки.** У каждого стикера может быть метка, цвет и крайний срок. Срочные задачи помечаются отдельно.
- **WIP-лимиты.** Для колонки можно задать предел числа задач. Пока лимит выбран, новые стикеры не добавляются и не переносятся, а счётчик показывает `3/3`.
- **Поиск по доске** (Ctrl+F) — фильтрует стикеры на лету и не меняет данные.
- **Удаление обратимо.** Удалённый стикер уходит в архив, а тост предлагает его вернуть. Архив старше 30 дней очищается при запуске.

### Несколько досок

- **Вкладки-закладки слева.** Доски создаются, переименовываются, удаляются и переставляются перетаскиванием. У каждой вкладки виден счётчик открытых задач.
- **Перенос между досками.** Если подержать стикер над вкладкой другой доски, она откроется прямо во время перетаскивания. Стикер можно сразу поставить в нужную колонку и место, не отпуская мышь.
- **Прокрутка вкладок без колеса.** Когда досок много, панель листается кнопками ▲/▼ и с клавиатуры. При перетаскивании стикера к верхнему или нижнему краю панель прокручивается сама.

### Оформление

- **Шесть тем доски** — «Крафт», «Рисовая бумага», «Голубая», «Пробковая доска» (стикеры на булавках), тёмный «Графит» и «Меловая доска». Тема хранится вместе с доской.
- **Спокойная палитра.** Тёплый письменный стол, полупрозрачные дорожки и пастельные стикеры без наклонов, чтобы текст оставался читаемым.
- **Свои шрифты.** Neucha для заголовков и стикеров, Caveat для акцентов. Анимации отключаются, если в системе включено уменьшение движения.

### Данные

- **Автосохранение.** Любое изменение сразу записывается в файл, а подпись в углу показывает время последнего сохранения.
- **Экспорт и импорт.** Доску можно сохранить в файл и загрузить обратно через диалог.
- **Локальное хранение.** Никакого облака и сетевых сервисов — только файл на компьютере.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+N` | Новая задача в пуле |
| `Ctrl+F` | Поиск по доске |
| `Ctrl+Enter` | Сохранить текст |
| `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` | Отменить / повторить правку текста |
| `Esc` | Закрыть окно или снять выделение |
| `Delete` | Удалить выбранные стикеры |

## Установка и запуск

### Готовые сборки

Скачай из раздела [Releases](https://github.com/Neuro-Storm/kanban/releases):

- **Linux** — `kanban-1.4.0-x86_64.AppImage`: `chmod +x` и запустить.
- **Windows** — `kanban-setup-1.4.0.exe`: обычный установщик.
- **macOS** — `kanban-1.4.0-arm64.dmg`.

### Из исходников

Нужен Node.js 20+ и npm.

```bash
npm install
npm start
```

Сборка дистрибутива:

```bash
npm run dist      # Linux AppImage
npm run dist:win  # Windows-установщик
npm run dist:mac  # macOS dmg, собирается на macOS
```

## Где лежат данные

Доска хранится в файле `kanban-board.json` в каталоге данных приложения:

- **Windows**: `%APPDATA%/Канбан/kanban-board.json`
- **macOS**: `~/Library/Application Support/Канбан/kanban-board.json`
- **Linux**: `~/.config/Канбан/kanban-board.json`

Файл можно скопировать или отредактировать при выключенном приложении. Рядом лежат резервные копии — `kanban-board.json.bak` и `.bak.1`.

## Разработка

Приложение собрано на Electron; ядро доски не зависит от интерфейса.

```bash
npm test          # юнит-тесты
npm run smoke     # смоук-тест в Electron
npm run shot      # кадр для README
```
